## CONFLICTS / UNCERTAINTIES

1. **Flag value & game‑ending format (biggest divergence, well‑supported):**
   - IQA = **30 pts** and the **catch ends the game** (win if ahead, else OT to leader+30).
   - USQ & MLQ = **35 pts**, catch does **not** end the game; it feeds a **set score
     (leader+60)** and the game is a race to that score.
   This is a genuine ruleset difference (not a source error) but it materially changes how
   a filmed ending should be read — confirm which body sanctioned the match before analyzing
   the final sequence.

2. **MLQ overtime:** MLQ clearly uses the USQ set‑score model (leader+60, first to reach
   wins). Whether MLQ ALSO defines a distinct overtime procedure like IQA's could **not be
   confirmed** — the MLQ "Game Procedures" page was egress‑blocked and search returned no
   usable text. Treat MLQ overtime as *unverified*; the set‑score race is the confirmed
   mechanism.

3. **MLQ "minimum two women" clause:** MLQ's current public pages (What is Quadball;
   Team Composition; 2025 franchise news) state a **minimum of two women** on pitch *in
   addition to* the 3/4 same‑gender maximum. One historical/evolution summary instead framed
   the sport as having **moved from a minimum‑two rule TO a maximum‑four rule** (implying
   minimums were dropped). Best reading: **USQ and IQA use pure gender‑neutral maximums with
   no minimum; MLQ's published wording uniquely retains a minimum‑women clause.** Exact
   enforcement wording of MLQ's minimum is uncertain — verify against the live MLQ rulebook
   if it matters to the analysis.

4. **USQ gender rule is division‑dependent, not fixed:** "3 max" vs "4 max" depends on the
   competition/season (e.g., 2025‑26: USQ Cup Club Competitive = 3 max; College = 4 max).
   A filmed USQ game could legally be either; determine the division before assuming which.

5. **Hoop spacing (minor):** USQ rulebook (authoritative) says the two side hoops sit
   **3 yd (108 in ≈ 2.74 m)** from the center 6‑ft hoop, matching the local pitch diagram.
   One IQA metric summary reported **~2.34 m** spacing. Likely a summary imprecision;
   the **hoop heights (3/4.5/6 ft) match across all three** — spacing is the only value in
   minor doubt for IQA.

6. **Seeker‑release timing across rulesets:** USQ specifies seekers released **10 s into the
   flag period** (Rulebook 3.4.5). IQA/MLQ release seekers after the seeker floor but the
   exact countdown wasn't verified line‑by‑line; the 20‑minute seeker floor itself is
   confirmed for all three.

7. **IQA & MLQ contact/substitution wording** was not verified line‑by‑line (their rulebook
   PDFs weren't directly fetchable). Stated as "substantively similar to USQ" based on shared
   heritage and search summaries; treat fine contact/foul details as USQ‑confirmed only.
